Ruang diskusi komunitas

Tanya, bahas, dan bantu sesama. Klik foto profil komentarmu untuk mengklaim akun (password + avatar) agar pesan tidak otomatis dihapus setelah 7 hari.

  1. Hormati sesama — tidak ada hinaan, spam, atau konten tidak pantas.
  2. Klaim profil: klik foto profil pada komentar atas namamu → set password + ganti avatar. Tanpa klaim, pesan dihapus otomatis setelah 7 hari.
  3. Balasan (reply) maksimal 3 level kedalaman.
  4. Topik sebaiknya seputar HTML, CSS, JS, JSON, dan desain web.
  5. Admin berhak menghapus komentar yang melanggar tanpa pemberitahuan.
