Apa itu SEO?

SEO (Search Engine Optimization) adalah praktik membuat halaman mudah dipahami mesin pencari dan relevan bagi manusia. Tujuannya bukan “menipu Google”, melainkan:

  • Halaman bisa ditemukan (indexing),
  • Isinya cocok dengan yang dicari orang (relevansi),
  • Pengalaman pengguna layak (mobile, cepat, jelas).

Untuk situs statis di web hosting, fondasinya sama dengan website lain: HTML rapi, konten berguna, sinyal teknis bersih.

Ekspektasi realistis: situs baru jarang langsung ranking #1 untuk kata kompetitif. Fokus dulu: terindeks → konten membantu → navigasi jelas. Posisi bagus mengikuti konsistensi, bukan satu trik semalam.

A. On-page SEO (yang kamu kontrol di kode)

Kerjakan ini di setiap halaman penting (index.html, sdlc.html, halaman panduan, dll.).

1

Title unik per halaman

Tag <title> di <head>. Ideal ±50–60 karakter, ada topik utama + brand.

<title>Panduan SEO — Silverhawk WebLearn</title>
2

Meta description

±140–160 karakter. Ringkas, menarik, bukan spam kata kunci. Bisa jadi cuplikan di hasil pencarian.

<meta name="description" content="Panduan step-by-step SEO untuk website statis di web hosting.">
3

Heading terstruktur

Satu H1 per halaman. H2/H3 mengikuti outline isi. Jangan loncat H1 → H4 tanpa alasan. Heading untuk struktur, bukan sekadar “teks besar”.

4

URL ramah

Pendek, huruf kecil, pakai tanda hubung. Contoh baik: /seo.html, /sdlc.html. Hindari parameter rumit jika tidak perlu.

5

Teks tautan deskriptif

Hindari “klik di sini”. Lebih baik: “Panduan SEO lengkap” atau “Modul belajar SDLC”.

6

Alt pada gambar

Jelaskan isi gambar. Membantu aksesibilitas dan memberi konteks ke mesin pencari.

<img src="assets/diagram-seo.png" alt="Diagram alur indexing Google Search Console">
7

Konten orisinal yang menjawab pertanyaan

Panjang tidak wajib. Yang penting berguna, bisa diikuti, dan tidak menjiplak mentah. Perbarui jika informasi sudah usang.

8

Mobile-friendly

Wajib ada viewport meta + layout responsif. Google mengutamakan mobile-first indexing.

<meta name="viewport" content="width=device-width, initial-scale=1.0">
9

HTTPS

Pastikan web hosting Anda memakai HTTPS (SSL/TLS aktif). Hampir semua hosting modern menyediakan sertifikat gratis (misalnya Let's Encrypt).

10

Open Graph (og:image)

Tidak langsung menaikkan ranking, tetapi meningkatkan CTR saat link dibagikan ke WA/sosmed. Siapkan gambar 1200×630 dan URL absolut di meta og:image. (Panduan detail og:image bisa menyusul di halaman terpisah.)

B. Agar Google mencatat situs (indexing)

Tanpa langkah ini, website bisa “hidup” tapi belum tentu muncul di pencarian.

1

Pastikan situs live di URL publik

Bukan localhost. Contoh: https://weblearn.silverhawk.web.id/.

2

Buka Google Search Console

Kunjungi search.google.com/search-console dan login dengan akun Google.

3

Tambah property

Pilih URL prefix (lebih sederhana untuk pemula), mis. https://weblearn.silverhawk.web.id/, atau Domain jika ingin mencakup semua subdomain.

4

Verifikasi kepemilikan

Pilih metode verifikasi yang paling mudah untuk web hosting Anda:

  • HTML file — unduh file verifikasi, taruh di root repo, commit & push, lalu klik Verify.
  • Meta tag — tempel di <head> index.html, deploy, Verify.
  • DNS TXT — jika kamu kelola DNS domain custom.
5

Buat dan submit sitemap

Lihat bagian Sitemap & robots.txt di bawah. Di Search Console: menu Sitemaps → masukkan sitemap.xml → Submit.

6

URL Inspection

Tempel URL beranda / halaman penting → Request indexing. Jangan spam request untuk ratusan URL sekaligus.

7

Tunggu dan pantau

Beberapa hari hingga beberapa minggu. Cek laporan Pages / Indexing. Status “Discovered / Crawled / Indexed” akan berubah bertahap.

8

Perbaiki error yang muncul

404, redirect salah, atau halaman diblokir robots — perbaiki di repo, deploy ulang, lalu minta index lagi jika perlu.

C. Sitemap.xml & robots.txt

File diletakkan di root situs (satu level dengan index.html).

Contoh sitemap.xml

<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <url>
    <loc>https://weblearn.silverhawk.web.id/</loc>
  </url>
  <url>
    <loc>https://weblearn.silverhawk.web.id/sdlc.html</loc>
  </url>
  <url>
    <loc>https://weblearn.silverhawk.web.id/seo.html</loc>
  </url>
</urlset>

Tambahkan URL lain yang ingin diutamakan (halaman panduan, artikel penting). Jangan masukkan URL yang noindex atau duplikat sia-sia.

Contoh robots.txt

User-agent: *
Allow: /

Sitemap: https://weblearn.silverhawk.web.id/sitemap.xml

Jangan Disallow: / jika kamu ingin situs bisa di-crawl. Hanya blokir folder yang memang privat (jarang diperlukan di situs publik).

Di zip WebLearn revisi ini, file sitemap.xml dan robots.txt contoh sudah disiapkan di root. Sesuaikan domain jika berbeda.

D. Trik & kebiasaan yang membantu di SERP

  • Intent pencarian — sesuaikan judul & isi dengan yang dicari orang (tutorial, definisi, checklist), bukan menjejalkan keyword.
  • E-E-A-T praktis — tunjukkan pengalaman: langkah yang bisa diikuti, contoh nyata, brand konsisten (Silverhawk WebLearn).
  • Internal link — dari beranda ke SEO/SDLC, antar panduan saling taut. Bantu Google pahami struktur situs.
  • Kecepatan — kompres gambar, JS tidak berlebihan. Pengalaman cepat tetap penting.
  • Hindari konten tipis / duplikat — rangkum dengan kata-katamu + contoh proyekmu.
  • Backlink alami — bagikan ke kelas, komunitas, repo; jangan beli link massal.
  • Pantau Search Console — lihat query yang dapat impression, lalu perkuat halaman itu.
