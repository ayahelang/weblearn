## 1. Latar Belakang
Tim pengajar membutuhkan portal pembelajaran interaktif agar mahasiswa memahami Software Development Life Cycle (SDLC) secara praktis, lengkap dengan contoh dokumen nyata yang bisa diunduh.

## 2. Tujuan Proyek (Objectives)
1. Menyediakan materi SDLC 7 tahapan yang interaktif.
2. Menyediakan glossary istilah teknis yang bisa diklik.
3. Menyediakan contoh dokumen (Project Charter, SRS, Test Case, dll.) yang bisa dilihat dan diunduh.
4. Menyediakan quiz untuk mengukur pemahaman.
5. Deploy ke web hosting dengan domain custom.

## 3. Ruang Lingkup (Scope)

### In-Scope
- Halaman SDLC terpisah (sdlc.html)
- 7 tahapan + detail deliverable & tugas
- 8 peran + contoh pertanyaan interview
- Glossary ≥ 50 istilah
- Contoh dokumen Markdown di folder docs/samples/
- Quiz interaktif + skor
- Integrasi opsional Google Apps Script

### Out-of-Scope
- Aplikasi mobile native
- Sistem pembayaran / subscription
- LMS penuh (grading otomatis, sertifikat digital engine)
- Multi-bahasa selain Bahasa Indonesia
