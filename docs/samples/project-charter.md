# Project Charter — Contoh

**Nama Proyek:** Portal Belajar WebLearn 2.0  
**Sponsor:** Kepala Program Studi  
**Project Manager:** [Nama PM]  
**Tanggal:** 2026-01-15  
**Versi:** 1.0

## 1. Tujuan Proyek
Membangun portal belajar interaktif yang mencakup materi HTML/CSS/JS/JSON dan modul SDLC lengkap, dapat diakses publik via GitHub Pages.

## 2. Ruang Lingkup (In-Scope)
- Modul video carousel & artikel
- Modul SDLC (tahapan, peran, quiz, glossary)
- Mode gelap/terang
- Integrasi opsional Google Apps Script untuk statistik

## 3. Di Luar Ruang Lingkup (Out-of-Scope)
- Mobile native app
- Sistem pembayaran
- LMS full-featured (grading otomatis, certificate engine)

## 4. Stakeholder Utama
| Peran | Nama / Unit | Kepentingan |
|-------|-------------|-------------|
| Sponsor | Kaprodi | Keberhasilan program |
| Pengguna | Mahasiswa & umum | Materi mudah dipahami |
| Tim Dev | Tim WebLearn | Deliver on time |

## 5. Milestone Utama
1. Kick-off & charter approved — Minggu 1  
2. Desain UI & data model selesai — Minggu 3  
3. Modul SDLC live — Minggu 6  
4. UAT & Go-live — Minggu 8  

## 6. Anggaran & Resource (Ringkas)
- 2 developer part-time, 1 designer  
- Hosting: GitHub Pages (gratis)  
- Backend opsional: Google Apps Script

| Risiko | Dampak | Mitigasi |
|--------|--------|----------|
| Scope creep materi | Tinggi | Change control formal |
| Keterlambatan konten | Sedang | Parallel writing + review |
