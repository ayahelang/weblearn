# Use Case — Contoh

## UC-01: Mempelajari tahapan SDLC
- **Aktor:** Pelajar
- **Prakondisi:** Pelajar membuka sdlc.html
- **Alur utama:**
  1. Pelajar melihat daftar 7 tahapan
  2. Pelajar memilih satu tahapan
  3. Sistem menampilkan detail (deskripsi, deliverable, tugas)
  4. Pelajar dapat mengklik istilah atau dokumen contoh
- **Hasil:** Pelajar memahami isi tahapan tersebut

## UC-02: Mengunduh contoh dokumen
- **Aktor:** Pelajar
- **Alur:** Pilih tahapan → klik nama dokumen → pratinjau → unduh
- **Hasil:** File tersimpan di perangkat pelajar
