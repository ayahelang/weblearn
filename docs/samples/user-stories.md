# User Stories + Acceptance Criteria — Contoh

**Proyek:** Proyek Website Portfolio  
**Format:** Agile User Story  
**Versi:** 1.0  

---

## Epic: Pembelajaran SDLC Interaktif

### US-01 — Melihat tahapan SDLC
**Sebagai** pelajar pemula,  
**saya ingin** melihat daftar 7 tahapan SDLC beserta ringkasan singkat,  
**agar** saya memahami alur besar pengembangan perangkat lunak sebelum masuk detail.

**Acceptance Criteria (Definition of Done):**
- [ ] Ditampilkan 7 kartu/timeline tahapan (Planning s/d Maintenance)
- [ ] Setiap kartu menampilkan nomor/ikon, judul, dan 1–2 kalimat ringkasan
- [ ] Klik kartu membuka panel detail: deskripsi lengkap, deliverable, tugas, mind-map
- [ ] Panel detail dapat ditutup kembali

**Story Points (estimasi):** 5

---

### US-02 — Memahami istilah teknis (Glossary)
**Sebagai** pelajar yang belum familiar dengan istilah industri,  
**saya ingin** mengklik kata seperti “SRS”, “UAT”, atau “CI/CD” dan langsung mendapat penjelasan,  
**agar** saya tidak harus mencari di mesin pencari dan kehilangan fokus.

**Acceptance Criteria:**
- [ ] Istilah yang terdaftar di glossary ditandai visual (underline / warna beda)
- [ ] Klik membuka modal dengan judul istilah + definisi
- [ ] Modal dapat ditutup dengan tombol, klik di luar, atau tombol Escape
- [ ] Minimal 50 istilah tercakup

---

### US-03 — Melihat & mengunduh contoh dokumen
**Sebagai** pelajar,  
**saya ingin** melihat contoh nyata Project Charter, SRS, Test Case, dll., lalu mengunduhnya,  
**agar** saya punya referensi konkret saat diminta membuat dokumen serupa.

**Acceptance Criteria:**
- [ ] Nama dokumen di daftar deliverable berupa tautan
- [ ] Klik membuka pratinjau isi dokumen (teks terbaca)
- [ ] Tombol “Unduh” mengunduh file (Markdown / teks)
- [ ] Semua deliverable utama di 7 tahap memiliki contoh

---

### US-04 — Latihan soal (Quiz)
**Sebagai** pelajar,  
**saya ingin** mengerjakan soal pilihan ganda tentang SDLC dan melihat skor + penjelasan,  
**agar** saya tahu bagian mana yang sudah dikuasai.

**Acceptance Criteria:**
- [ ] Tombol “Mulai Quiz” memulai sesi
- [ ] Soal ditampilkan satu per satu (minimal 8 soal acak dari bank soal)
- [ ] Setelah menjawab, opsi benar/salah ditandai dan penjelasan muncul
- [ ] Di akhir, skor total ditampilkan; pengguna dapat mengulang

---

### US-05 — Mempelajari peran & interview
**Sebagai** mahasiswa yang akan magang/kerja,  
**saya ingin** mengetahui tanggung jawab tiap peran (PM, BA, QA, dll.) dan contoh pertanyaan wawancara,  
**agar** saya siap menjawab saat interview.

**Acceptance Criteria:**
- [ ] 8 peran ditampilkan
- [ ] Klik peran menampilkan deskripsi, daftar tanggung jawab, dan minimal 2 contoh Q&A interview

---

## Catatan untuk Product Owner
Prioritas disarankan: US-01 → US-03 → US-02 → US-04 → US-05 (MoSCoW: Must / Must / Must / Should / Should).
