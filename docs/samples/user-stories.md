# User Stories + Acceptance Criteria — Contoh

## Epic: Modul SDLC

### US-01 — Melihat tahapan SDLC
**Sebagai** pelajar,  
**saya ingin** melihat daftar 7 tahapan SDLC beserta ringkasan,  
**agar** saya memahami alur pengembangan perangkat lunak secara keseluruhan.

**Acceptance Criteria:**
- [ ] Ditampilkan 7 kartu tahapan (Planning s/d Maintenance)
- [ ] Setiap kartu menampilkan judul, ikon, dan deskripsi singkat
- [ ] Klik kartu membuka detail: deliverable, tugas, mind-map
- [ ] Istilah di deskripsi dapat diklik (glossary modal)

### US-02 — Glossary interaktif
**Sebagai** pelajar,  
**saya ingin** mengklik istilah teknis dan mendapat penjelasan,  
**agar** saya tidak perlu mencari di tempat lain.

**Acceptance Criteria:**
- [ ] Istilah yang terdaftar di glossary ditandai (underline / warna berbeda)
- [ ] Klik membuka modal dengan definisi lengkap
- [ ] Modal bisa ditutup dengan tombol, klik luar, atau Escape

### US-03 — Unduh contoh dokumen
**Sebagai** pelajar,  
**saya ingin** melihat dan mengunduh contoh Project Charter, SRS, Test Case, dll.,  
**agar** saya punya referensi konkret saat praktik.

**Acceptance Criteria:**
- [ ] Nama dokumen di daftar deliverable berupa tautan
- [ ] Klik membuka pratinjau (markdown dirender) + tombol unduh
- [ ] File tersedia dalam format .md (bisa disimpan / dicetak)
